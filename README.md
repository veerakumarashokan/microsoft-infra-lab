# Microsoft Infrastructure Lab

This repository focuses on building practical skills in Microsoft-based infrastructure environments, including Windows systems, networking, and cloud technologies.

It is designed to document hands-on labs, troubleshooting scenarios, and real-world workflows aligned with enterprise environments that rely on Microsoft tools and services.

---

## Purpose

- Develop strong fundamentals in Windows-based systems and networking  
- Build practical troubleshooting skills using real-world scenarios  
- Learn cloud infrastructure concepts using Microsoft Azure  
- Create a structured path toward infrastructure and network engineering roles  

---

## Scope

This repository covers:

- Windows system configuration and troubleshooting  
- Network configuration and issue diagnosis in Windows environments  
- Azure infrastructure and networking concepts  
- Real-world operational scenarios and lab-based learning  

---

## Structure

- `md-102/` → Windows endpoint management and system-level tasks  
- `az-104/` → Azure administration and infrastructure  
- `az-700/` → Azure networking concepts and implementations  
- `labs/` → Practical troubleshooting and configuration labs  
- `notes/` → Key concepts and learnings  

---

## Approach

This repository emphasizes practical learning over theory.

Each lab or module focuses on:
- Identifying real-world problems  
- Applying step-by-step troubleshooting  
- Understanding the underlying concepts  
- Verifying results  

---

## Goal

To build a strong foundation in Microsoft infrastructure while progressing toward advanced networking and cloud roles.
