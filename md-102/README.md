# MD-102

This section focuses on concepts, notes, and practical learning related to Microsoft Endpoint Administration and Windows-based enterprise environments.

It is aligned with the MD-102 learning path while emphasizing practical understanding over exam memorization.

---

## Purpose

- Learn Windows endpoint administration concepts  
- Understand device management and configuration  
- Build troubleshooting skills in Windows environments  
- Develop familiarity with enterprise endpoint workflows  

---

## Focus Areas

Topics may include:

- Windows configuration and management  
- User and device administration  
- Networking and connectivity troubleshooting  
- Security and policy management  
- System maintenance and diagnostics  

---

## Approach

Learning is combined with practical labs and real-world troubleshooting scenarios to reinforce understanding and operational thinking.

---

## Goal

To build a strong foundation in Microsoft endpoint administration and prepare for infrastructure-related technical roles.
